---
title: "worktree open: reopen a git worktree"
description: "worktree open reopens an existing git worktree in your editor or a Herdr space by branch name, or from an interactive picker."
---

Open an existing worktree in your configured editor, or as a Herdr space when `opener` is set to
`herdr`. With `opener` set to `none`, nothing is opened and `Worktree already exists at <path>` is printed.

## Usage

```bash
worktree open [branch]
```

## Examples

```bash
worktree open feature/add-bulk-actions
```

If you omit the branch, the CLI presents an interactive picker. A
[non-interactive run](/worktree/commands/branch/#non-interactive-runs) has no picker: without the argument it exits
`2` with `worktree: no default for the branch to open; pass <branchName>`.
