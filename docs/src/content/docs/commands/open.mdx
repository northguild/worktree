---
title: "worktree open: reopen a git worktree"
description: "worktree open reopens an existing git worktree in your editor, a Herdr space or a Rex session by branch name, or from an interactive picker."
---

Open an existing worktree in your configured editor, as a Herdr space when `opener` is set to
`herdr`, or as a Rex session when it is `rex`. With `opener` set to `auto`, it opens in the Herdr or Rex
the command runs inside (Herdr first if both), else in the editor. With `opener` set to `none`, nothing is
opened and `Worktree already exists at <path>` is printed.

## Usage

```bash
worktree open [branch]
```

## Examples

```bash
worktree open feature/add-bulk-actions
```

If you omit the branch, the CLI presents an interactive picker. A
[non-interactive run](/worktree/commands/branch/#non-interactive-runs) has no picker: without the argument it exits
`2` with `worktree: no default for the branch to open; pass <branchName>`.
