## Install

<Tabs syncKey="pm">
  <TabItem label="npm">

```bash
npm install -g @northguild/worktree
```

  </TabItem>
  <TabItem label="pnpm">

```bash
pnpm add -g @northguild/worktree
```

  </TabItem>
  <TabItem label="yarn">

```bash
yarn global add @northguild/worktree
```

  </TabItem>
  <TabItem label="bun">

```bash
bun add -g @northguild/worktree
```

  </TabItem>
</Tabs>

Then [Getting Started](/worktree/getting-started/) sets a source branch and an editor and creates your first worktree.
